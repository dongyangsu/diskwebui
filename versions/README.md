# 版本归档

| 版本 | 日期 | 源码包 | 说明 |
|---|---|---|---|
| **v1.0** | 2026-09-16 | [diskwebui_v1_src.tar.gz](v1.0/diskwebui_v1_src.tar.gz) | 第一版：多机管理 + 硬盘检测 + 缺陷判定 + 手工格式化 + 命令行。此版存在 14 个已知缺陷（自动检测 TDZ 崩溃、`-m` 误伤同型号盘、`already running` 死循环、长任务被 3600s 误判超时等）。 |
| **v2.0** | 2026-09-20 | [diskwebui_v2_src.tar.gz](v2.0/diskwebui_v2_src.tar.gz) | 修复上述 14 个开发期问题 + 9 个部署期问题；新增**插盘自动检测/自动格式化/自动续格（主从模型）**、自制非阻塞弹窗、机器维度接口、静态文件 no-cache、主源优先同步、磁盘空间保护与标签生成脚本。经 6 层测试体系（静态/单元/集成/系统/验收/跨机）回归通过。 |
| **v3.0** | 2026-09-24 | [diskwebui_v3_src.tar.gz](v3.0/diskwebui_v3_src.tar.gz) | **当前版本**。机器列表全面升级：**排序**（多条件/自定义序列/中文拼音笔画/空白置末）、**列筛选 + 全局搜索 + 快速筛选 + 命名视图 + 多用户各自保存**、**批量操作**、**导入导出 9 种格式（含 Excel/YAML）**、**打印**、**分页**、IP 多地址悬停小窗、冻结表头/条件格式/密度/键盘操作；**全站 5 个页面自适应**（页面本体无滚动条、各区域内部滚动、桌面/平板/手机/高 DPI 适配）；修复 5 个真 bug（打印不可用、`sync` 404、`test/connect` 未知接口、IP 校验过宽、PUT 偏好存不上）；新增 UI 回归套件 `scripts/ui_suite.mjs`（65 项断言，支持 http/https）与按用户的列表偏好接口。 |

> 每个版本相对上一版的**增加 / 修改 / 删除**，见根目录 [CHANGELOG.md](../CHANGELOG.md)。
> v1.0/v2.0 的完整问题清单与解决方式见 [`docs/硬盘检测与格式化 Web 管理界面规划（V0.2 实现版）.md`](../docs/硬盘检测与格式化%20Web%20管理界面规划（V0.2%20实现版）.md) 第八、九、十章。
